💬 Para que sirve este material
Este manual es una guia de consulta rapida para el equipo de soporte tecnico N1 de Somos Internet. Fue construido para que cualquier analista — nuevo, antiguo o lider — pueda encontrar la informacion que necesita de forma rapida, clara y sin tener que buscar en documentos PDF.

Cada seccion explica en lenguaje simple como funciona cada router o herramienta, que puede hacer el analista N1, que no puede hacer, y como identificar y resolver los problemas mas comunes.

En el menu de la izquierda encontraras todas las secciones organizadas en tres grupos:

💡 Como leer los terminos tecnicos
A lo largo del manual encontraras palabras subrayadas en verde con letra cursiva — como esta: failover. Al pasar el mouse encima de esas palabras aparece una ventana con la explicacion en lenguaje simple. No es necesario memorizar los terminos — el manual los explica cada vez que aparecen.

Puertos del router — para que sirve cada uno
LAN1 — el puerto rapido (2.5 Gbps)
Es el unico puerto que soporta hasta 2.5 Gbps. Clientes con plan 2.5 Gbps deben conectar su equipo aqui. Se usa para: el computador principal, un switch de red, o cualquier equipo que necesite la maxima velocidad.
LAN2, LAN3, LAN4 — puertos estandar (1 Gbps)
Soportan hasta 1 Gbps cada uno. Se usan para: televisores por cable, computadores secundarios, consolas de videojuegos, decodificadores. Si un cliente con plan 2.5 Gbps conecta su equipo aqui, nunca va a sentir la velocidad que contrato.
WAN1 — entrada principal de internet
Por aqui entra el internet desde la red de Somos. Es la conexion principal a 2.5 Gbps.
WAN2 — entrada de respaldo
Conexion de respaldo a 1 Gbps. Se activa automaticamente si WAN1 falla.

Phantom + Convertidor de fibra
Phantom estandar con un aparato que convierte la señal de fibra optica a cable de red normal
Que hace el convertidor de fibra (Media Converter)Media Converter = convierte la señal de fibra optica (luz) a cable UTP que el router puede entender. Sin el, el router no recibe internet aunque este perfecto.
La fibra optica es un cable muy delgado por donde viaja internet en forma de luz. El convertidor toma esa luz y la transforma en una señal electrica normal que el router puede leer — como un traductor entre dos idiomas. Si el convertidor falla, el router no recibe internet aunque este en perfecto estado. Siempre revisar el convertidor primero.
⚠ Revisar siempre el convertidor antes de concluir que el problema es el router o la red.

Comportamiento del sistema — escenarios importantes
Cambio automatico al respaldo (Failover automatico WAN1 a WAN2)Failover = el router detecta que WAN1 fallo y cambia automaticamente a WAN2. No requiere ninguna accion del analista.
El router detecta la falla en WAN1 — ya sea un corte fisico de fibra (Hard Failure)Hard Failure = falla fisica total. Por ejemplo, el cable de fibra se corto. El router lo detecta en menos de 100 milisegundos. o una falla logica como DNS o HTTP (Soft Failure)Soft Failure = falla logica. El cable esta conectado pero el internet no funciona bien. El router tarda unos 5 segundos en confirmarlo antes de cambiar al respaldo. — y cambia solo a WAN2.

Que siente el cliente: una pausa muy breve (menos de 100ms en falla fisica, unos 5 segundos en falla logica). Si el plan es de 2.5 Gbps, puede sentir que la velocidad bajo — porque WAN2 solo llega a 1 Gbps.
Recuperando la conexion principal (Estado Monitoring)Monitoring = estado transitorio donde el router intenta volver a usar WAN1 despues de una caida. El servicio sigue activo por WAN2. No realizar acciones.
El router esta intentando restablecer WAN1. El servicio sigue activo por WAN2. No hacer nada — esperar y monitorear.
Cambiando constantemente entre conexiones (Estado Flapping)Flapping = el router cambia entre WAN1 y WAN2 sin parar porque las dos estan inestables. Como un interruptor que no para. El cliente siente cortes intermitentes. Requiere escalar a N2.
El router oscila entre WAN1 y WAN2 constantemente porque las dos estan inestables. El cliente siente la navegacion erratica o con cortes continuos. Escalar a N2.

TP-Link Deco M5
Sistema de red en malla · Se administra desde una interfaz web · Puede tener varios equipos conectados en el mismo hogar
Que es el Deco M5 y como funciona
El Deco M5 es un sistema de red en malla (mesh)Mesh = red de malla. En vez de un solo router, hay varios equipos Deco en la casa conectados entre si. Todos dan la misma red WiFi para cubrir toda la vivienda sin zonas sin senal. — puede haber uno o varios equipos Deco en la misma casa, todos dando la misma red WiFi.

Se administra desde una pagina web que se abre en el computador del analista. Esa pagina tiene una barra con varias secciones — cada seccion se llama pestanaPestana = cada una de las secciones de la pagina web del router. Al hacer clic en una, cambia la pantalla y muestra la configuracion de esa parte especifica. y controla una parte diferente del router:

Internet (conexion con Somos) · LAN (red interna) · Wireless (WiFi) · QoS (prioridad de trafico) · DHCP Server (asignacion de IPs) · Parental Controls (control parental) · Port Forwarding (apertura de puertos) · System (configuracion general).

2. Como verificar que el router tiene internet — pantalla "EWAN Connection Status"
Que debe verificar el analista en esta pantalla
Esta pantalla se llama EWAN Connection Status y muestra como esta la conexion del router con Somos. El analista debe confirmar que estos cuatro campos tengan informacion:

● Direccion IP publica (Public IPv4)IP publica = la direccion que Somos le asigna al router para que pueda comunicarse con internet. Es como la direccion de una casa — sin ella, el router no sabe donde enviar ni recibir datos. Si aparece en blanco, Somos aun no le ha asignado esa direccion al equipo.: si esta en blanco, el router no tiene comunicacion con Somos — no hay internet. Es como si el router no tuviera direccion para recibir el servicio.

● Tipo de conexion (IPv4 Connection Type)IPv4 Connection Type = como el router recibe su configuracion de internet. En modo Dynamic IP, Somos le asigna todo automaticamente. Si esta en otro modo, el router no sabe como conectarse y pierde el internet.: debe decir Dynamic IP. Si dice otra cosa, el router no puede conectarse con Somos correctamente — escalar a N2.

● Velocidad del puerto (Negotiation Speed)Negotiation Speed = la velocidad fisica a la que el puerto del router esta operando. Debe mostrar 1000Mbps Full Duplex para garantizar que no hay un cuello de botella por cable o hardware.: debe decir 1000Mbps Full Duplex. Si dice 100Mbps, significa que el cable esta limitando la velocidad — como un tubo estrecho que no deja pasar suficiente agua. A esto se le llama cuello de botellaCuello de botella = un punto en la conexion que limita la velocidad de todo lo demas. Aunque el plan sea de 1 Gbps, si el cable fisico solo soporta 100Mbps, el cliente nunca va a recibir mas que eso. Como un embudo estrecho.. Revisar el cable de red entre el router y el punto de conexion.

● Modo de operacion: debe decir Wi-Fi Router Mode.
⛔ Si la IP publica aparece en blanco, el equipo no tiene internet. No continuar con otras revisiones — el problema esta en la autenticacion con Somos. Escalar a N2.
⚠ Si la Negotiation Speed dice 100Mbps en vez de 1000Mbps: el cable fisico esta limitando la velocidad a 100Mbps — aunque el plan del cliente sea de 1 Gbps, no va a recibir mas que eso. Antes de escalar, pedirle al cliente que revise si el cable de red esta bien conectado o si esta doblado o dañado.
3. Prueba de velocidad integrada
Para que sirve esta prueba
Esta herramienta mide la velocidad directamente desde el Deco — descarta que el problema sea del WiFi del cliente o de su dispositivo.

● Download / Upload: velocidad real de bajada y subida en Mbps. Comparar con el plan del cliente.
● Latencia (ms)Latencia = tiempo que tarda la senal en ir y volver. Idealmente menos de 5ms. Si es alta, el cliente siente lentitud aunque la velocidad sea buena.: idealmente menos de 5ms. Si es alta, el cliente siente lentitud aunque la velocidad sea buena.
● Metodo de medicion: usa tecnologia de OoklaOokla = la empresa detras de Speedtest.net, la herramienta de medicion de velocidad mas usada en el mundo. El Deco la integra directamente para diagnosticos confiables. — es la misma tecnologia de Speedtest.net.

5. Reinicios automaticos programados — pestana "Schedule Regular Restarts"
Para que sirve programar reinicios automaticos
El router, al igual que un computador, acumula procesos en memoria con el tiempo. Si no se reinicia periodicamente, puede volverse lento o inestable. Un reinicio programado lo hace automaticamente en horario donde el cliente no usa internet.

Por que funciona:
● Libera la memoria (RAM)RAM = la memoria de trabajo del router. Con el tiempo se va llenando de procesos residuales que hacen que el router responda mas lento. El reinicio la limpia completamente. del router — evita que se "pegue" tras semanas de uso.
● Limpia la tabla de direcciones (NAT y DHCP)NAT y DHCP = tablas internas que el router usa para dirigir el trafico y asignar IPs. Con el tiempo se llenan de registros de dispositivos que ya no estan en casa, lo que puede causar conflictos de conexion. — evita conflictos con dispositivos nuevos que se quieran conectar.
● Refresca el canal WiFi — al reiniciar, el Vilo vuelve a escanear y elige el canal con menos interferencia.
● Previene la "lentitud fantasma" — muchos reportes de lentitud se resuelven con un simple reinicio. Al programarlo, reducimos la probabilidad de que el cliente llame por eso.

Configuracion recomendada:
● Frecuencia: una vez por semana. En hogares con mas de 20 dispositivos inteligentes (IoT)IoT = dispositivos inteligentes del hogar: camaras, bombillas, asistentes de voz, etc. Consumen conexiones constantemente y pueden saturar al router mas rapidamente., dos veces por semana.
● Horario: entre las 2:00 AM y 4:00 AM — cuando nadie usa internet en casa.

Velocidad de bajada y subida (Descarga / Subida en Mbps)Mbps = Megabits por segundo. 1000 Mbps = 1 Gbps. Comparar con el plan del cliente: si tiene 500 Mbps y el test da 480 Mbps, esta bien.
La velocidad real que llega al router. Comparar siempre con el plan contratado del cliente.
Tiempo de respuesta (Latencia / Ping)Latencia = tiempo que tarda la senal en ir del router al servidor y volver. Idealmente menos de 5ms. Si es alta, el cliente siente lentitud aunque la velocidad sea buena. — idealmente menos de 5ms
Cuanto tarda la senal en ir y volver. Si es alta, el cliente siente la navegacion lenta aunque tenga buena velocidad.
Estabilidad de la respuesta (Jitter)Jitter = variabilidad del tiempo de respuesta. Si unas veces tarda 0.5ms y otras 50ms, el jitter es alto. Afecta videollamadas y juegos online. Idealmente menos de 1ms. — idealmente menos de 1ms
Que tan estable es el tiempo de respuesta. 1ms significa 1 milisegundo — es una milesimasegundo de tiempo. Entre mas bajo, mas estable la conexion. Afecta directamente videollamadas y juegos online.
Perdida de datos (Packet Loss)Packet Loss = porcentaje de paquetes de datos que se pierden durante la transmision. Debe ser siempre 0.00%. Cualquier perdida provoca lentitud, cortes o inestabilidad en la navegacion. — debe ser 0.00%
Si hay perdida de datos, la navegacion se siente cortada o inestable. Cualquier valor mayor a 0% es señal de problema.

Cuando debe usarlo el analista
✓ Usarlo cuando
● El WiFi esta lento aunque la velocidad por cable este bien.

● El cliente tiene desconexiones o cortes intermitentes en el WiFi.

● El cliente dice "internet anda mas lento en la noche" — tipico de edificios donde muchos vecinos usan el mismo canal.

● La señal WiFi es debil en algunas zonas del hogar (a veces resuelve, a veces no — depende de la causa).
✗ NO usarlo cuando
● El internet esta completamente caido — no hay servicio.

● El router esta apagado o sin energia.

● El problema es de la conexion WAN, no del WiFi.

Glosario de terminos
Palabras tecnicas explicadas en lenguaje cotidiano
WAN
La entrada de internet al router. WAN1 = principal (2.5 Gbps en Phantom-X), WAN2 = respaldo (1 Gbps).
Failover
Cambio automatico a la conexion de respaldo cuando la principal falla. Como un generador que se prende solo.
Down / Degraded
Down = caida total. Degraded = senal con problemas. Ambos pueden activar el failover.
Flapping
El router cambia entre WAN1 y WAN2 constantemente. El cliente siente cortes intermitentes. Escalar a N2.
LAN
Puertos para equipos del cliente. Phantom-X: LAN1 = 2.5 Gbps, LAN2-4 = tope 1 Gbps.
Gbps / Mbps
Unidades de velocidad de internet. 1 Gbps = 1000 Mbps.
Media Converter
Convertidor de fibra optica a cable de red normal. Sin el el router con fibra no funciona.
MAC Address
La cedula del router. Codigo unico que lo identifica. Ejemplo: 04:8F:00:08:49:15.
Uptime
Tiempo que lleva el router encendido sin reiniciarse. Meses de uptime pueden justificar un reinicio preventivo.
Latencia / Ping
Tiempo que tarda la senal en ir y volver. Idealmente menos de 5ms.
Jitter
Variabilidad del ping. Afecta videollamadas y juegos. Idealmente menos de 1ms.
Packet Loss
Perdida de datos. Debe ser 0.00%. Cualquier valor mayor indica problema.
Mesh / Red de malla
Varios routers en la misma casa conectados entre si para dar cobertura en toda la vivienda.
Band Steering
Funcion que emite un solo nombre de WiFi y decide automaticamente entre 2.4 GHz y 5 GHz.
IoT
Dispositivos inteligentes del hogar: camaras, bombillas, asistentes. Se recomienda conectarlos en red separada.
DNS
Servidor que traduce nombres de sitios a direcciones IP. Cambiarlo a 8.8.8.8 puede mejorar la navegacion.
Link Rate
Velocidad maxima negociada entre un dispositivo y el router. Link Rate bajo = dispositivo lejos o mala senal.
Escalar a N2
Pasar el caso a analista de nivel 2. Se hace cuando el problema esta fuera de lo que N1 puede resolver.
